**用字 nuance**：
- 回報 bug 時,「打開後是 404」用 **"it opens a 404 (page)"** 或 **"it 404s"**（把 404 當動詞，工程圈很常用）都很道地。例如：*"The link 404s."*（這連結會 404。）
- 「請確認」在請對方調查問題時，**"Could you look into it?"** 或 **"Please investigate."** 比直譯的 "please confirm" 更貼切——因為 "confirm" 偏「確認某事為真」，而你要的是「去查清楚原因」。
- 好的 bug report 結構：**重現步驟 + 預期 vs 實際結果**。你已經給了重現步驟（從我的開團紀錄→看詳情）和實際結果（404），很完整 👍
