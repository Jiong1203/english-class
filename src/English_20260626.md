**English Corner:**
這次你沒有輸入英文句子（需求是用中文描述的），所以這裡提供你這次需求的自然英文說法，幫你累積詞彙：

> "Let's hide the *type* and *category* fields in the UI for now, and just store the data as `EVENT`."

幾個值得記住的用法：
- **hide ... for now** — 「先暫時隱藏…」，`for now` 精準表達「目前先這樣、之後可能會改」的語氣，比單純 `hide` 更貼近你的原意。
- **store the data as `EVENT`** — 「以 EVENT 儲存資料」，介系詞用 **as**（表示「當作某種值/型別」），不要用 `store to` 或 `store in EVENT`。

下次若用英文交辦類似任務，可以試著套用這個句型。
