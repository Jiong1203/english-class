**English Corner:**

你這次的提問是中文（「請問有加入到『團團』選單內嗎?」），對應自然的英文說法：

> "Did you also add it to the `團團` menu?"

用字說明（以中文解釋）：
- **Did you add...?** 用過去式詢問「（剛才）有沒有做某事」最直接。
- **also**：對應「也」，放在主詞與動詞之間（`Did you also add`）是最自然的位置。
- 若想更口語確認，也可說 **"Is it in the `團團` menu too?"**（強調「結果狀態」而非「動作」）。

這是很實用的 review/確認句型，工作上常用來追問某項變更是否完整。👍

**English Corner:**

你這次是中文指令（「幫前端 create 表單加上預選當前群組」），對應自然英文：

> "Add current-group pre-selection to the frontend create form."

用字說明（以中文解釋）：

- 也可說 **"Make the create form default to the current group."**，用 `default to` 表達「預設選為」，語感更口語。

這是清楚的功能需求句，方向明確。👍
