**English Corner:**

這次你用中文下指令,我提供自然的英文說法供參考:

> "The form shows a 422 error when the end time is earlier than the start time, but the UI doesn't clearly tell the user why. Please improve the error message for a non-technical user."

幾個用詞重點:
- **doesn't clearly tell the user why**(沒清楚告訴使用者原因)比直譯的 "doesn't show the reason clearly" 更口語、更自然。
- 「無軟體背景的使用者」最道地的說法是 **non-technical user**(而非 "user without software background")——這是業界標準用語。
- 「優化提示」用 **improve the error message** 即可;若想更精準可說 **make the error message clearer**。

> Session: `2e373eda` · 00:54:24

**English Corner:**

這次你的指令是中文「幫我按照規則推上去,要用 en」,提供自然的英文說法:

> "Push it following the rules, and use English for the commit message."

用詞重點:
- **following the rules**(按照規則)是最自然的講法;這裡的 "rules" 指 commit 規範與分支策略。
- 「推上去」用 **push it** 即可,工程語境下大家都懂是 push to remote;若要明確可說 **push it to the remote branch**。
- 若想更精確表達「用英文寫 commit 訊息」,完整說法是 **write the commit message in English**。
