**English Corner:**

你這次用中文，以下是自然的英文說法：

> "You didn't pull first. You should have pulled the latest changes before starting!"

用法說明：
- **should have + 過去分詞**：表示「過去本來應該做、但沒做」，帶有責備或遺憾的語氣，例如 *You should have checked first.*
- **pull the latest changes**：「拉取最新進度」的標準說法，也可以說 *get the latest code* 或 *sync with the remote*。
- 語氣較委婉的版本：*Next time, please pull before making changes.*
