**English Corner:**

你這則有個字用錯了，先講這個：

> ❌ 「**例外**，看板裡有顯示...」
> ✅ 「**另外**，看板裡有顯示...」

**「例外」≠「另外」** —— 這組中文很容易混：

| 中文 | 意思 | 英文 |
|---|---|---|
| **例外** | 不適用一般規則的特殊情況 | exception |
| **另外** | 追加一件事 | also / additionally / one more thing |

你想表達的是「還有一件事」，所以是「另外」。英文對應：

> **"Also, the dashboard shows "(期間累計)" but the original doesn't — please remove that too."**

順帶一提，中文的「例外」如果真要用在這裡，句意會變成「這是個例外情況」，讀者會等你說明為什麼特殊，結果你接的是新需求，就會卡住。

**英文的「另外」有幾種，語氣不同：**

| 說法 | 位置 | 語氣 |
|---|---|---|
| **Also,** | 句首 | 最常用、中性 |
| **Additionally,** | 句首 | 偏正式、書面 |
| **One more thing —** | 句首 | 口語，帶「差點忘了」的感覺 |
| **On a separate note,** | 句首 | 轉到不相關的另一件事 |

你這次兩個需求是相關的（都在 KPI 卡上），所以 **`Also`** 最合適；如果是完全另一個話題，用 `On a separate note` 會更清楚。

👍 另外你這句「這邊都有 AVG，但我看看板裡沒有」結構很好——**先指出來源有什麼、再指出目標缺什麼**，這是最不會誤解的比對句型。英文同構：

> "The original has an AVG row for each KPI, but I don't see it on the dashboard — please add it."

`I don't see it` 比 `it doesn't have` 更軟、更像回報觀察而非指責，在協作情境很好用。

**English Corner:**

你這句的英文：

> **"Don't split the AVG into a second card — it wastes too much layout space."**

**「浪費版面空間」的幾種說法**，精確度不同：

| 英文 | 語感 |
|---|---|
| **wastes space** | 最直白，你的意思 |
| **takes up too much space** | 佔太多空間（中性，不含「浪費」的批評） |
| **leaves a lot of dead space** | 留下大片空白（**最精準**——問題是「空著沒用」） |
| **feels sparse** | 看起來空洞（描述觀感） |

你的情況其實是 **dead space**：主卡上半部空著、AVG 又自己佔一塊。這個字很值得記：

> "The top half of the card is **dead space** — pull the AVG inside instead."

**另外注意「拆成」的英文：**

| 中文 | 英文 | 備註 |
|---|---|---|
| 拆成兩張卡 | **split into** two cards | `split into` 是固定搭配 |
| 合併成一張 | **merge into** one card | 反向操作 |
| 收進卡片裡 | **pull ... inside** / **inline it** | `inline` 當動詞很工程 |

`inline` 這個字剛好就是我這次腳本的命名（`inline_kpi_avg.py`）——當動詞時意思是「把原本獨立的東西併進主體裡」，前端講 inline CSS、inline function 都是同一個概念，描述你這個需求非常精準：

> "Can you **inline** the AVG into the main card?"
> （可以把 AVG 併進主卡裡嗎？）

👍 你這則用「這樣版面空間會很浪費」把理由講出來，很好——**說出理由讓我能判斷解法**。如果只說「不要拆成兩張卡」，我可能只是把兩張卡靠得更近，而不是重新配置卡內的垂直對齊。
