1. **句末加句號**：完整的英文句子應該以句號結尾。雖然在聊天訊息或 PR comment 裡省略句號很常見、不會被誤會，但若是寫在正式文件（commit message、issue comment）建議補上。

這種命令式（imperative mood）英文是 git commit message 的標準格式 —— Linus Torvalds 在 Linux kernel 開發規範中就強調 commit message 第一行要用 imperative，例如：
- ✅ `Fix race condition in scheduler`

- ❌ `This commit fixes...`（贅字）

判斷標準：你的 commit subject 應該能填進這句話 —— `If applied, this commit will <你的 commit subject>`，例如 `If applied, this commit will fix #8 and #10` ✓ 通順。
