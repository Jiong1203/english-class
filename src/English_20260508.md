你的問題 "When user cancel order, does the system send flex message to group?" 文法上正確，但有個小地方可以更自然：

| 你的句子 | 更自然的說法 |
|---|---|
| When user cancel order | When a user cancels an order |

**Why:** 英文的可數名詞前通常需要冠詞（"a user"），動詞也需配合第三人稱單數（"cancels"）。你的句子少了 "a" 和 "-s"，在口語中可以理解，但在書面表達中建議補上。

替代說法：
- "Does the system send a flex message to the group when an order is cancelled?"（被動語態，更正式）
- "On order cancellation, is a flex message sent to the LINE group?"（工程師風格的簡潔表達）
