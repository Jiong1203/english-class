你這次用中文，以下是自然的英文說法：

> "You can fix #1, but #2 is intentional — the point is to number the slots automatically — so leave it. We'll deal with the 5,000-character limit if we ever actually hit it."

- **intentional / by design**：「故意這樣設計的」。工程上很常說 *"That's by design."*
- **leave it (as is)**：「不用改、保持原樣」，比 *don't fix it* 自然。
- **cross that bridge when we come to it**：「真的遇到再說」的道地慣用語，例如 *"We'll cross that bridge when we come to it."*
