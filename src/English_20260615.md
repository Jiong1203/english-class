**English Corner:**

你這則直接貼了錯誤訊息、沒有英文句子。補充一個這次很核心的詞:

- **falsy / truthy**:JS 裡 `null`、`""`、`0`、`undefined`(真正的 undefined 值)都是 *falsy*,但**字串** `"undefined"` 是 *truthy* —— 這正是 `|| 'null'` 擋不住它的原因。描述這個 bug 時很實用:
  > "The string `\"undefined\"` is **truthy**, so the `|| 'null'` fallback never kicks in."
  (字串 `"undefined"` 是 truthy,所以 `|| 'null'` 這個退路根本不會被觸發。)
- **kick in**:「(機制)開始作用/生效」的道地片語,講 fallback、防呆何時觸發時很好用。
